# dramanda

The personal website of Dr. Amanda Foo-Ryland, an international keynote speaker and best selling author. It is a single page that introduces her work and shows her show reel, books, talks and videos, the clients she has worked with, and what people say about her. Visitors can send an enquiry about booking her to speak.

It is a fast, static site built with plain HTML, Tailwind CSS and a little JavaScript.
